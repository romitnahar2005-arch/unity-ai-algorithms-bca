// Core AI Modules

Five AI Systems — Built From Scratch

🔄
01 // FSM

Finite State Machine

Generic C# implementation with type-safe state enumeration. Dictionary-based O(1) state lookup. 6 states with OnEnter / OnUpdate / OnExit lifecycle hooks.

CPU: <0.05ms / NPC
🌳
02 // BT

Behavior Tree

Composite-Decorator-Leaf pattern. Sequence (AND), Selector (OR), Inverter, Condition, Action, and Wait nodes. Priority-ordered combat decision logic. Emergent flanking observed.

CPU: 0.1–0.4ms / NPC
🗺️
03 // A*

A* Pathfinding

Binary min-heap priority queue (O log n). Hash set Closed Set for O(1) lookup. Admissible Euclidean heuristic with ×1.2 inadmissibility for speed.

50×50 grid: <0.3ms
🧭
04 // NavMesh

NavMesh Navigation

3 agent profiles: Guard, Scout, Brute. Off-mesh link traversal. NavMeshObstacle Carve mode for incremental runtime updates. 5× faster than custom A* for 3D environments.

Recalc: 0.31s avg
🌫️
05 // FUZZY

Fuzzy Logic Difficulty

Mamdani inference engine. Trapezoidal membership functions. Inputs: player distance + health → Output: real-time aggression multiplier. Continuous adaptive difficulty with no discrete jumps.

CPU: <0.05ms / NPC
🚶
06 // STEERING

Steering Behaviors

Seek, Flee, Wander, Separation, Alignment, Cohesion, Avoidance. Priority-based force truncation in corridors. Emergent squad behavior through weighted vector composition.

Boids-style flocking
